# Azure 3-Tier Architecture Project

## Project Overview
Built a real-time Azure 3-tier architecture using Azure Portal.

## Services Used
- Azure Virtual Network
- Subnets
- Azure Virtual Machines
- Azure Load Balancer
- Azure SQL Database
- NSG
- Azure Monitor
- Recovery Services Vault

## Architecture

Users -> Load Balancer -> Web VMs -> App VM -> Azure SQL Database

## Features
- High Availability
- Secure Networking
- Traffic Distribution
- Monitoring & Backup

## Skills Demonstrated
Azure Administration, Networking, Compute, Security, Monitoring
